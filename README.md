# Ration Shop Digital Queue Management System

A web-based digital queue management system for ration shops developed using HTML, CSS, and JavaScript.

## Features
- Online token booking for scheduled visits
- Real-time live queue tracking and token display
- Dedicated priority service for senior citizens
- Automated queue alerts and notifications
- Simple and user-friendly interface for citizens and shop operators

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open rationshop.html in a web browser.
3. Enter the required details to book a token or check queue status.
4. Manage or view your queue turn in real time.

## Project Purpose
The project demonstrates basic web development, user input handling, queue scheduling logic, priority queue management, and dynamic display of real-time results.
